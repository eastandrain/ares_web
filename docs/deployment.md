# 사내 배포 안내

## 개발 테스트

백엔드는 `8000` 포트에서, 프론트엔드는 `npm run dev`로 실행합니다. 메인 화면 주소는 다음과 같습니다.

```
http://localhost:5173/ares
```

Vite 개발 서버는 모든 네트워크 인터페이스(`0.0.0.0`)에서 요청을 받습니다. 같은 사내망 사용자는 다음 주소로 접속할 수 있습니다.

```
http://<서버-사내-IP>:5173/ares
```

Windows 방화벽이 해당 포트의 인바운드 연결을 허용해야 할 수 있습니다.

## 운영 배포 구조

사내 사용자가 접속하는 운영 환경에서는 Nginx 또는 IIS를 웹 서버로 사용합니다.

```
사내 사용자 -> Nginx/IIS -> React 정적 파일 (/ares)
                         -> FastAPI (/api)
                                    -> 사내 DB
```

웹 서버는 브라우저 새로고침 후에도 `/hbm/assy` 같은 화면 주소를 유지할 수 있도록, 프론트엔드 경로 요청에 `index.html`을 반환하도록 설정해야 합니다. DB 연결 문자열은 `backend/.env`에만 저장하고 프론트엔드 파일에는 넣지 않습니다.

## 파이프라인 경계

`ares_pipeline`은 별도의 프로그램입니다. 원본 제조 데이터를 처리하고 검증된 결과를 사내 DB에 적재합니다. FastAPI는 이렇게 준비된 결과를 읽기만 합니다. 이 분리를 유지하면 사용자가 대시보드를 열 때마다 대용량 배치 처리가 실행되지 않아 역할과 운영 범위가 명확해집니다.
